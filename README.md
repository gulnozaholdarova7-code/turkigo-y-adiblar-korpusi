# Turkigo‘y adiblar — elektron ilmiy korpus

Lutfiy, Sakkokiy, Gadoiy, Hofiz Xorazmiy va Atoyi devonlarining ilmiy nashrlari asosida
tuzilayotgan ochiq manbali elektron korpus.

**Sayt:** https://gulnozaholdarova7-code.github.io/turkigo-y-adiblar-korpusi/

## Imkoniyatlar
- adib devonlarini ko‘rish (bayt, vazn, nashr va sahifa bilan);
- misralar bo‘yicha qidiruv (KWIC);
- korpus statistikasi (matn va so‘z soni) avtomatik hisoblanadi.

## Tuzilishi
| Fayl | Vazifasi |
|---|---|
| `index.html` | sahifa |
| `korpus.js` | ko‘rish, qidiruv, statistika mexanizmi |
| `korpus-data.js` | korpus matnlari va ularning nashr ma’lumotlari |

Yangi matn qo‘shish: `korpus-data.js` faylidagi namunaga qarang.
